## Vasyl Krychun

Author of **StemJSON**: generative UI for native mobile. AI agents write a whole
feature as one JSON module, and the iOS and Android runtimes run it natively on
SwiftUI and Jetpack Compose.

**Make a module**
- From your AI chat: [MCP server](https://stemjson.com/mcp/)
- On iPhone or iPad: [StemStudio AI](https://stemjson.com/stemstudio/)
- Ready-made: [StemJSON catalog](https://stemjson.com/catalog)

**Run it**
- Specification: [StemJSON](https://github.com/vkrychun/StemJSON)
- Runtimes: [iOS](https://github.com/vkrychun/stem-runtime-swift) · [Android](https://github.com/vkrychun/stem-runtime-kotlin)
- Examples: [iOS](https://github.com/vkrychun/stem-examples-swift) · [Android](https://github.com/vkrychun/stem-examples-kotlin)
